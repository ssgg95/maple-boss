# 🍁 메짱이 (MEJJANGI) - 메이플스토리 보스 유틸리티

> 메이플스토리 주간 보스 결정석 계산, 파티 분배 및 캐릭터별 보스 클리어 현황을 간편하게 관리할 수 있는 웹 서비스입니다.

🔗 **배포 사이트 바로가기:** [https://maple-boss-gamma.vercel.app/](https://maple-boss-gamma.vercel.app/)

---

## 📌 프로젝트 소개
매주 여러 캐릭터로 주간 보스를 처치하면서 결정석 수익과 보스 리워드를 계산하기 위해 개발했습니다. 직관적인 UI를 통해 캐릭터별 보스 현황을 한눈에 파악하고 관리할 수 있습니다.

### ✨ 주요 기능
- **주간 보스 체크리스트:** 캐릭터별 처치한 보스 목록 체크 및 주간 수익 자동 합산
- **결정석 수익 및 분배 계산기:** 파티 인원수에 따른 1인당 결정석 수익 자동 계산
- **회원 계정 연동:** 아이디 및 대표 캐릭터 등록을 통한 개인별 보스 데이터 저장 및 관리

## 🔒 보안 및 개인정보 처리
- 회원가입 시 비밀번호는 단방향 암호화(Hashing)를 거쳐 안전하게 저장됩니다.
- 최소한의 정보(아이디, 암호화된 비밀번호, 대표 캐릭터명)만을 수집하며, 회원 탈퇴 시 즉시 파기됩니다.
